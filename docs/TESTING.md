# 标注一致性仲裁｜测试说明
上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 业务已知答案

复算平票、一致票及 κ；拒绝重复投票。分母为零返回空 κ。通过接口验证分歧批次不能直接通过、非法裁决标签拒绝、独立审核人逐项裁决后才能发布。

## 1.3 专项回归

标注仲裁分歧依据：每个样本保留初判原因：票数不足、并列、未达一致率或一致通过；条件重叠时按此顺序解释，裁决后仍保留初判依据。 运行 AlgorithmTest.enterpriseEvidenceAndBoundaries 复核边界；全套共 14 条 Java 测试，另有 3 条前端导入测试。

## 1.2 新增回归

在以下 1.1 的基线之上，新增两条 HTTP 测试：只允许作者按正确版本撤回、非法撤回不改变数据；撤回与复核并发时只有一笔成功。共 13 条 Java 测试。维护者可另用 Node 18+ 运行 `node --test scripts/import.test.mjs`，验证本项目导入样本、错误行、类型和未知字段。正式发布另从干净目录启动，MySQL 实测六个并发重试只生成一个结果。

## 工程回归

`./mvnw -f backend/pom.xml clean package` 运行 3 个算法测试和 10 个 HTTP/初始化测试。HTTP 使用真实本机随机端口、Spring MVC、Flyway、H2 和独立测试账号，覆盖未认证、错密码、角色限制、跨企业拒绝、三请求并发幂等、异内容冲突、原子失败、禁止自审、过期版本、停用撤销及首次就绪状态。测试账号只存在测试进程中。 新增测试覆盖自助改密撤销全部会话、密码不进审计、标题筛选和复核队列隔离。

`python3 scripts/smoke.py` 在临时库启动打包后的真实 JAR，检查首页、JS、CSS、健康状态、账号、样例、导出所用的详情接口、幂等提交及落盘重启。两个进程退出后删除自检临时库，不操作用户的业务库。

本批次交付另做了 Chrome 浏览器实操（登录、载入样例、运行、查看明细、进入管理端）及 MySQL 8.4.5 独立数据库实测（从空 schema 初始化、首次登录、提交、同键重试、第二账号复核和状态查询）。README 的图片来自上述真实界面。Compose 编排脚本已提供，本机无 Docker daemon，未把原生 MySQL 验证记为 Compose 实测。

**边界：** 未做用户实际流量的负载/容量认证、客户生产 SSO 或跨地域灾备验收。正确性测试不能替代客户真实数据的算法效果评估。
